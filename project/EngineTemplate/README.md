# EngineTemplate

このフォルダは、本エンジンを使って**新しいゲームプロジェクトを立ち上げる際に、新しいリポジトリのルートへそのままコピーする**ためのテンプレート一式です。

## 使い方

1. 新しいゲーム用のリポジトリ（フォルダ）を用意する
2. このフォルダの中身（`CLAUDE.md`と`.claude\rules\cpp-dx12.md`）を新リポジトリのルート直下にコピーする
3. `CLAUDE.md`内の以下の箇所を新しいゲームに合わせて書き換える
   - 「プロジェクト概要」（ゲーム内容の説明）
   - 「現在の実装状態」「未完了タスク」（新規なら空のままでよい）
   - 「現時点でエンジンに無い機能」（実装が進んだら随時更新する）
4. エンジン本体のコード（`Engine`フォルダ、`Resources\shaders`等）も一緒にコピーする（このテンプレートには含まれていない。エンジン本体は本リポジトリのGit履歴、または分岐時点のコピーから持っていくこと）

## このテンプレートに含まれるもの

- `CLAUDE.md` — Claude Codeとの運用ルール（会話は日本語、差分提示、ビルドはユーザー側、ドキュメント追記ルール等）＋本エンジンのアーキテクチャ概要
- `.claude\rules\cpp-dx12.md` — C++/DX12のコーディング規約（命名規則、エラーハンドリング、DX12固有の注意点）
- `ClaudeLog\codeLog.txt` / `collisionLog.txt` / `project.txt` — 中身は空（見出しのみ）のドキュメント置き場。新規ゲームでの実装が進むにつれて追記していく前提（フォルダ名は好みで変更可。変更したら`CLAUDE.md`内の記述も揃えて直すこと）

## 含まれていないもの（別途判断・作業が必要）

- エンジン本体のソースコード一式（`Engine`フォルダ、`Resources\shaders`等）
- `README.md`（エンジン基礎化の記録。新規ゲームでは不要になるか、内容を作り直すことになる）
